# Benzola

Dark gothic personal page — black & white aesthetic with animated portals, synced lyrics player and glass UI.

Built with **React + TypeScript + Vite + Framer Motion**.

## Features

- Animated glass player with frequency visualizer
- Synced Russian lyrics for *Every Time*
- Portal-style social links (TikTok · Telegram · Spotify)
- Atmospheric B&W backgrounds with fog & vignette
- Fully responsive

## Dev

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Deploy the `dist/` folder (GitHub Pages base path is `/Benzola/`).
